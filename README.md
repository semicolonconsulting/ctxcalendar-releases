# Ctx Calendar — releases

Downloads for **Ctx Calendar**, a desktop calendar for engineers and consultants who juggle several client calendar accounts (Google, Outlook, iCloud) in one view.

- **Download:** see [Releases](../../releases/latest) and pick `Ctx.Calendar_<version>_aarch64.dmg` (Apple Silicon Macs). The app is signed with Developer ID and notarized by Apple.
- **Updates:** Ctx checks this page for new versions (Settings › General › App › Check for updates).
- **More:** https://www.semicolon.consulting/ctx-calendar

This repository holds release files only. The source code is private.
